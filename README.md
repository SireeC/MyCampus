# MyCampus – Institute Website Replica

A static website replica of an IT training institute's website, developed using HTML5 and CSS3. This project recreates the institute's website layout and visual appearance, showcasing its courses, student success stories, training benefits, company associations, and team members.

## Project Preview

![myCampus output](screenshot/myCampus_ss.png)

## Features

Navigation Bar: Provides navigation links to different sections of the website.

Hero Section: Highlights the institute's offerings and course information.

Student Success Stories: Showcases student testimonials and placement success stories.

Training Benefits: Highlights the learning benefits and opportunities offered by the institute.

About the Institute: Presents information about the institute, its teaching approach, and experience.

Company Showcase: Displays company logos representing students' career destinations.

Career Transformation Courses: Highlights different IT training programs, including:

- Java Full Stack with Cloud & DevOps

- Python with Data Science

- MERN Full Stack with Cloud & DevOps

- Python Full Stack with GenAI

Team & Mentors: Displays team member and mentor profiles.

Contact Section: Includes an inquiry section for visitors.

Footer: Contains institute information, useful links, and social media icons.

## Current Limitations

The website is currently designed for desktop viewing.

Responsive layouts for mobile and tablet screens have not yet been implemented.

Contact and inquiry sections are visual UI components and do not currently have backend integration.
